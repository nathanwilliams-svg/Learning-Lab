How the activities work

Select your class, open an activity, choose a level, and follow the on-screen instructions. No ChatGPT account needed.

These are classroom practice apps. Teacher controls are local to each browser and are not password-protected. Code answers may be visible to students in the page source. Python needs access to an external runtime on first use.
