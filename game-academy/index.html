🧑‍🏫 Teacher guide & project checks

These are student-managed completion checks, not automatically graded assignments. Have students demonstrate the requested feature before marking complete. Review working game behavior and code explanations rather than code keywords alone.

Suggested schedule: Weeks 1–3: graphics and movement; weeks 4–6: collisions, score and logic; weeks 7–9: arrays, levels and menus; weeks 10–12: original game design, debugging, and showcase.

Assessment: Functionality 40%, typed-code understanding 30%, testing and improvement 20%, collaboration and reflection 10%.

Export: Students can download a JSON progress backup. It includes their typed code and completion marks. Files remain on the device until a student shares them with you. There are no online accounts, cloud sync, or teacher monitoring.

Nipher RoboKnights · Self-contained canvas game engine · No external libraries or student accounts required. Saving uses browser local storage, which may be unavailable or cleared by district device policies.
